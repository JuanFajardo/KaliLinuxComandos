1. 1. ¿Cómo funciona el DNS?

Domain Name System (Sistema de Nombres de Dominio) – traduce nombres legibles (ej. www.ejemplo.com) a direcciones IP.
Ayuda a identificar el dominio o la URL de :
- Pagina Web
- Correos
- Servidores

3. Herramientas para consulta DNS

dig (Domain Information Groper): Resgistro: A, MX, NS, TXT, AXFR, etc. 
                $ dig ucb.edu.bo
                $ dig ucb.edu.bo NS
                $ dig ucb.edu.bo NS +short

5. Transferencia de Zona (Zone Transfer)

🔹 AXFR (Full Zone Transfer): Transfiere la zona completa.
🔸 IXFR (Incremental Zone Transfer): Solo envía cambios recientes (más eficiente).

5.1 Cómo ocurre una mala configuración

# Desde cualquier máquina: 
dig @ns.ejemplo.com ejemplo.com AXFR
Si la consulta devuelve todos los registros, la zona está completamente expuesta.

Demo práctica: Comprobación de AXFR

# 1. Identificar servidores NS del objetivo
dig ucb.edu.bo +short NS

# 2. Probar transferencia contra cada NS
dig @ns1.ucb.edu.bo ucb.edu.bo AXFR +short

# 3. Usar herramienta whatweb, httpx
whatweb -i example.com
